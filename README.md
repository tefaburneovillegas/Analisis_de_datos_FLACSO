
# Análisis de datos con Python - FLACSO Ecuador

Este repositorio reúne los materiales y ejercicios prácticos del curso **Introducción al análisis de datos con Python**, impartido en FLACSO Ecuador y desarrollado por [Diversa](https://diversa.studio/).

## Objetivos del curso

Al finalizar el curso, las y los participantes podrán:

- Comprender qué es un dato y cómo se organiza.
- Utilizar Google Colab para escribir y ejecutar código.
- Reconocer los elementos básicos de Python.
- Trabajar con variables, listas, diccionarios, condicionales y funciones.
- Organizar y explorar conjuntos de datos sencillos.
- Interpretar resultados de manera crítica y responsable.
- Documentar y comunicar un análisis de forma clara.

## ¿Cómo utilizar los notebooks?

La forma más sencilla de trabajar con los materiales es utilizar **Google Colab** directamente desde el navegador:

1. Abre el enlace de la clase en la tabla anterior.
2. Inicia sesión con una cuenta de Google.
3. Selecciona **Archivo → Guardar una copia en Drive**.
4. Ejecuta cada celda haciendo clic en el botón ▶ o utilizando `Shift + Enter`.
5. Lee las explicaciones y modifica los ejemplos para observar qué cambia.
6. Resuelve los ejercicios en tu propia copia.

No necesitas instalar Python ni descargar programas para trabajar en Google Colab.

## ¿Cómo está organizado un notebook?

Los archivos `.ipynb` son cuadernos interactivos que combinan:

- **Celdas de texto:** contienen explicaciones e instrucciones.
- **Celdas de código:** permiten escribir y ejecutar Python.
- **Resultados:** aparecen debajo de cada celda después de ejecutarla.

Las celdas deben ejecutarse en orden. Si una variable no existe o aparece un resultado inesperado, prueba ejecutar nuevamente las celdas anteriores.

## Recomendaciones para aprender

- Escribe parte del código por tu cuenta; no te limites a ejecutar las celdas.
- Cambia los valores de los ejemplos y compara los resultados.
- Lee con calma la última línea de los mensajes de error.
- Utiliza nombres de variables claros y relacionados con la información.
- Agrega comentarios con `#` para explicar lo que hace tu código.
- Guarda una copia de cada notebook antes de modificarlo.
- Pregunta cuando algo no esté claro: programar también implica aprender a formular preguntas.

## Uso responsable de los datos

Analizar datos no consiste únicamente en aplicar técnicas. También implica preguntarnos:

- ¿Quién produjo los datos y con qué propósito?
- ¿Quién decidió qué información debía convertirse en datos?
- ¿Qué personas o experiencias podrían no estar representadas?
- ¿Qué información personal o sensible debemos proteger?
- ¿Qué límites tienen los datos y nuestras conclusiones?
- ¿Cómo pueden afectar los resultados a distintas personas o comunidades?

Durante el curso abordaremos el análisis de datos como una práctica **técnica, crítica y responsable**.
